# Neon Rush
# Dana Jadunauth

A neon-themed typing racing game. Complete three laps before the CPU or other players to win.

## Play

https://neon-rush-arcade-dana.sparseridge16.chatgpt.site

Use a desktop browser and a keyboard. No installation or extra packages are needed.

## Getting Started

- **Single-player:** Choose a theme and car color, then select **Single-Player**.
- **Multiplayer:** Create a room, enter your name, and share the room link. The host starts when everyone is ready. Up to 12 players can join.

## Rules and Controls

- Type the text exactly, including capitals, spaces, and punctuation.
- Correct typing moves your car forward.
- Mistakes slow you down. Correct the highlighted character to continue.
- Complete all three laps first to win.
- Press **Esc** to open the menu and resume or return to the main menu.
- Use the music button and volume slider to control sound.

Single-player pauses when the menu opens. Multiplayer keeps running. If the host leaves, everyone returns to the main menu.
